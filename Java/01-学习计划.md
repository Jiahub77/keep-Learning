# 12 周 Java 后端学习计划

## 目标与技术栈

目标：在工作中独立开发、维护一个包含权限、事务、测试和部署的 Java 后端模块。每周学习 10～15 小时，以业务实践为主，不以面试刷题为主。

技术栈：JDK 21、IntelliJ IDEA、Maven、Spring Boot、MyBatis、MySQL、JUnit 5、Docker。Spring Boot 使用学习开始时仍受支持的稳定版本及其匹配文档。

练习项目：独立商品管理服务，可参考 BizVision 业务；使用独立测试数据库和虚构数据，不连接生产环境。

## 周计划

| 周次 | 重点 | 交付与验收 |
|---|---|---|
| 1 | Java 类型、类、接口、访问控制 | 控制台商品管理，完成一次断点调试 |
| 2 | 集合、泛型、异常、Lambda、Stream、日期和文件 | 商品筛选排序，JSON 文件保存与读取 |
| 3 | Maven、Spring Boot、依赖注入、分层 | 内存版商品 REST API，与 React 联调 |
| 4 | MyBatis、MySQL、分页、迁移脚本 | 数据库版商品查询，能从空库重建 |
| 5 | DTO、参数校验、异常处理、日志 | 非法参数和不存在的商品有明确响应 |
| 6 | 事务、回滚、并发更新 | 库存调整与变更记录原子提交，库存不为负 |
| 7 | Spring Security、密码哈希、JWT | 登录、角色权限、商品归属校验 |
| 8 | 图片上传与文件校验 | 大小和类型校验，失败时处理文件与数据一致性 |
| 9 | JUnit、Mockito、集成测试、OpenAPI | 权限、事务、参数校验测试及接口文档 |
| 10 | Redis、线程池、线程安全基础 | 商品详情缓存，修改后失效 |
| 11 | Linux、Docker、环境配置、健康检查 | Compose 启动应用、MySQL、Redis |
| 12 | 联调、排错、交付整理 | 完整业务流程、启动说明、排错记录 |

## 每周节奏

- 周一、周二各 1 小时：知识学习与最小示例。
- 周三、周四各 1.5 小时：应用到项目。
- 周末 5～8 小时：业务实现、测试、联调和复盘。
- 每周保留一个可运行的 Git 提交，记录问题及解决方式。

先学到能解决当前问题的程度，再逐步深入。微服务、Spring Cloud、Kubernetes、复杂 JVM 调优后置。时间不足时优先保留权限、事务、测试和部署，Redis 与并发进阶顺延。

## 最终验收

- 从空测试库按说明启动服务，前端可用。
- 商品增删改查、分页、上传、登录与权限完整。
- 非法输入、未登录及跨用户访问得到正确处理。
- 并发库存扣减不为负，失败操作正确回滚。
- 关键测试可重复通过，日志不泄露密码或 Token。
- 能跟踪一次请求，并解释分层、事务、索引、缓存的设计。
