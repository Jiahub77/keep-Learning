## 四、简答题

### 21. 绝对路径与相对路径（5 分）

- 绝对路径从根目录 `/` 开始，不依赖当前工作目录。例如：`/etc/hosts`。（2 分）
- 相对路径以当前工作目录为起点。例如：`docs/notes.txt` 或 `../notes.txt`。（2 分）
- 能明确说明二者是否依赖当前工作目录。（1 分）

### 22. 常见目录用途（每项 1 分）

| 目录 | 主要用途 |
|---|---|
| `/etc` | 存放系统及服务的配置文件 |
| `/home` | 通常存放普通用户的主目录 |
| `/var` | 存放日志、缓存等经常变化的数据 |
| `/tmp` | 存放临时文件，可能被系统定期清理 |
| `/root` | root 用户的主目录 |

### 23. 权限解释（5 分）

- 文件所有者：`rwx`，可读、可写、可执行。（1 分）
- 文件所属组：`r-x`，可读、可执行，不可写。（1 分）
- 其他用户：`r--`，仅可读。（1 分）
- 对应八进制权限：`754`。（2 分）

其中，`r = 4`、`w = 2`、`x = 1`。

### 24. 软件包管理命令（5 分）

- `sudo apt update`：从配置的软件源获取软件包信息，更新本地索引。（1 分）
- `sudo apt upgrade`：根据本地索引升级已安装的软件包。（1 分）
- `sudo apt install curl`：安装 `curl` 软件包，必要时安装其依赖；若已安装，也可能将其升级。（1 分）
- 能说明更新索引与升级软件包的区别。（1 分）
- 能说明 `sudo` 用于以授权身份执行这些需要管理权限的操作。（1 分）

### 27. 写入内容与检索文本

```bash
mkdir -p ~/ubuntu-exam
cd ~/ubuntu-exam

printf '%s\n' \
  'Ubuntu is a Linux distribution.' \
  'I am learning Linux commands.' \
  'Practice makes progress.' > study.txt

grep -n 'Linux' study.txt
wc -l study.txt
```

`grep` 预期输出：

```text
1:Ubuntu is a Linux distribution.
2:I am learning Linux commands.
```

`wc -l` 统计结果应为 **3 行**。

使用 `cat` 配合 here-document，或其他能准确写入三行内容的方法，同样得分。

### 28. 权限、磁盘与网络

```bash
chmod u+x ~/ubuntu-exam/run.sh
df -h
ip addr
ping -c 4 127.0.0.1
```

其中，`ip a` 也可得分；`127.0.0.1` 是本机回环地址，测试它不依赖外部网络。
