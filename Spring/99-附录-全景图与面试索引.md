## 2. Bean 创建流程与两种注入位置速查

```
refresh()
  └─ finishBeanFactoryInitialization()
       └─ preInstantiateSingletons()          ← 预实例化所有非懒加载单例
            └─ getBean(beanName)
                 └─ doGetBean()
                      └─ createBean()
                           └─ doCreateBean()  ★ 核心
                                │
                                ├─ createBeanInstance()
                                │    └─ hasConstructorArgumentValues() == true ?
                                │         └─ ConstructorResolver#autowireConstructor()
                                │              └─ 逐个参数 resolveValueIfNecessary()
                                │                   · ref  → getBean()  递归
                                │                   · value→ TypeConverter
                                │              └─ ctor.newInstance(args)   ★ 【构造注入】
                                │
                                ├─ addSingletonFactory()   三级缓存，暴露早期引用
                                │
                                ├─ populateBean()
                                │    └─ applyPropertyValues()
                                │         ├─ BeanDefinitionValueResolver（ref → getBean）
                                │         └─ BeanWrapperImpl#setPropertyValues
                                │              └─ processLocalProperty()
                                │                   ├─ Introspector → PropertyDescriptor
                                │                   ├─ convertForProperty()  类型转换
                                │                   └─ Method.invoke()       ★ 【Set 注入】
                                │
                                └─ initializeBean()
                                     ├─ invokeAwareMethods()
                                     ├─ postProcessBeforeInitialization()
                                     ├─ invokeInitMethods()   init-method / afterPropertiesSet
                                     └─ postProcessAfterInitialization()  ★ AOP 代理
```

## 4. 一句话记忆卡

```
IoC    = 把 new 和 set 的权力交出去
DI     = 交出去之后，容器怎么把依赖塞回来
Set    = 先造空壳（无参构造）→ 再反射调 setter      → populateBean
构造   = 先解析依赖（getBean）→ 再反射 newInstance  → createBeanInstance
循环依赖：Set 能解（三级缓存），构造不能（依赖必须先于对象）
背压   = 消费者 request(n)，生产者按需发
MVC    = 一请求一线程，I/O 阻塞
WebFlux= 事件循环，少量线程扛高并发，但一个阻塞调用毁全部
```
